Web Technology

HTML stands for HyperText Markup Language. It is used to design web pages using a markup language. HTML is the combination of Hypertext and Markup language. Hypertext defines the link between web pages, while markup language defines the structure of a web page using tags.

C Programming

C is a procedural programming language developed by Dennis Ritchie. Its low-level memory access, compact set of keywords and efficient execution make it suitable for operating systems, compilers and system-level software.

Java

Java has been one of the most popular programming languages for many years. Java is object-oriented and compiles source code into bytecode, which runs on the Java Virtual Machine regardless of the underlying architecture.
