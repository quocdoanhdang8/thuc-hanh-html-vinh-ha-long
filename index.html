Thực hành nhúng CSS vào HTML

Phần 1: Inline Style

Tiêu đề sử dụng Inline CSS

Đoạn văn này được thay đổi màu sắc bằng thuộc tính style trực tiếp trong thẻ HTML.

Phần 2: Internal Style

Tiêu đề sử dụng Internal CSS

Đoạn văn này được định dạng bằng thẻ style đặt trong phần head của trang HTML.

Phần 3: External Style

Tiêu đề sử dụng External CSS

Đoạn văn này được định dạng bằng file CSS bên ngoài có tên style.css.
