# Thực hành HTML cơ bản - Vịnh Hạ Long

Bài thực hành xây dựng trang web giới thiệu **Vịnh Hạ Long - Kỳ quan Thiên nhiên Thế giới** bằng các thẻ HTML cơ bản.

## Nội dung chính

- Sử dụng thẻ `<h1>` để tạo tiêu đề chính.
- Sử dụng thẻ `<p>` để tạo các đoạn văn.
- Sử dụng thẻ `<img>` để chèn hình ảnh.
- Sử dụng thẻ `<a>` để tạo liên kết đến Wikipedia.

## File bài làm

- `halong_bay.html`

## Cách xem

Mở file `halong_bay.html` bằng trình duyệt web.
